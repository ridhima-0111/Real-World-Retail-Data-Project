# Real-world Data Project (Retail Domain)

## Project Title

Retail Sales Analysis and Prediction using Superstore Dataset

## Objective

Analyze retail sales data and build a prediction model using machine learning.

## Tools Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

## Analysis Performed

* Sales by Category
* Sales by Region
* Sales Prediction

## Key Findings

* Technology category generated high sales.
* Regional sales vary significantly.
* Quantity and Discount influence sales performance.

## Machine Learning Model

Linear Regression

## Visualizations Generated

* Retail Sales by Category
* Retail Sales by Region

## Conclusion

This project demonstrates how data science can be applied to retail business data for decision-making and sales prediction.
